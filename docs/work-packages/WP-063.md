# WP-063 - Formato visual truncado del factor de mayoría

## Estado documental

`APROBADO`

## Objetivo

Mostrar el campo `factor` con exactamente dos decimales en toda superficie de usuario, truncando los decimales excedentes sin redondear y sin modificar el valor real almacenado o transportado.

## Resultado esperado

Un factor como `0.6789` se presenta como `0.67`, `0.6` como `0.60` y `1` como `1.00`, mientras el dominio, CSV, DTO y cálculos conservan su precisión original.

## Dependencias

- WP-062.

## Decisiones humanas cerradas

1. Mostrar **exactamente dos decimales**.
2. Si existen más de dos decimales, **truncar**, nunca redondear.
3. El cambio es exclusivamente de representación; no alterar datos ni cálculos.

## Criterios de aceptación

1. `0.6789` se muestra `0.67`.
2. `0.6799` se muestra `0.67`, no `0.68`.
3. `0.6` se muestra `0.60`.
4. `1` se muestra `1.00`.
5. El valor enviado/recibido y usado en cálculos conserva la precisión previa.
6. La solución evita errores de redondeo binario que puedan convertir un valor válido en un centésimo inferior incorrecto.
7. Todas las superficies visibles existentes usan el mismo criterio.
